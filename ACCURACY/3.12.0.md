# SwiftSci 3.12.0 Accuracy & Numerical Parity

> [!WARNING]
> **v3.13.2 Historical Audit Notice**: Includes audited `Benchmarks/Runs/standard-3.12.0` and `migration-3.12.0` records alongside legacy `--research` checks (`SwiftSciBenchmarks --research`, `Benchmarks/Python/accuracy_benchmarks.py`) retired in `v3.13.2`. Additionally, `v3.13.2` clarified that `ExponentialSmoothing` minimizes SSE (not Gaussian likelihood), `ARIMAModel` uses Hannan-Rissanen conditional OLS (with G-033/G-037 defects fixed in `v3.13.2`), and `TreeSHAP` covers DecisionTree/RandomForest regressors only (G-035/G-036).

Numerical, predictive, and statistical parity comparing **SwiftSci 3.12.0** (Swift 6, Accelerate BLAS/LAPACK & Metal) against **NumPy 2.5.3**, **Pandas 3.0.6**, **Scikit-Learn 1.8.0**, **SciPy 1.18.1**, **Statsmodels 0.14.6**, **NLTK 3.10.3**, **SHAP 0.46.0**, and **PyTorch 2.11.0**.

## Correctness & Mathematical Enhancements in 3.12.0 (PR #80–#102)

| Subsystem | Prior Behavior (`3.11.0`) | `3.12.0` Enhancement | Mathematical & Protocol Impact |
| :--- | :--- | :--- | :--- |
| **`ProbabilityMatrix` & GPU BCE (`SwiftML`)** | `endIndex` clamped to `max(rows.count, 6)` repeating rows on $0 < N < 6$; GPU BCE gradient drifted at $z=0$. | Fixed `endIndex == rows.count`, strict bounds-checked `subscript`, `Equatable`, exact GPU BCE gradients, and multiclass Core ML softmax axis. | Exact cardinality for all $N \ge 0$, exact gradient parity at $z=0$, and faithful Core ML export (PR #90, #91, #102). |
| **PCA & `HNSWIndex` (`SwiftCluster`)** | Restored PCA did not validate `totalVariance`; `HNSWIndex` truncated mismatched vector dimensions via `min`. | Validated positive finite `totalVariance` on restore, preserved LAPACK SVD workspace queries, and added `dimension: Int?` / `HNSWError`. | Guaranteed EVR consistency on persisted PCA and strict dimension checks without silent truncation (PR #89, #101, #102). |
| **Embeddings & NMS (`SwiftNLP`, `SwiftVision`)** | Local text embeddings used randomized Swift `Hasher`; YOLOv8 NMS was class-agnostic. | Replaced `Hasher` with deterministic 64-bit FNV-1a token hashing; delegated YOLOv8 to class-aware `NonMaximumSuppression.filter`. | Bit-identical cross-process embeddings (PR #96) and preserved co-located distinct-class detections (PR #102). |
| **Correlation, Metrics & Plots (`SwiftStats`, `SwiftForecast`, `SwiftVisualization`)** | `spearmanCorrelation` lacked `requireNoNaN`; heatmaps dropped NaNs per column; ROC curves were tie-order dependent. | Added `requireNoNaN`, finite non-negative `epsilon` checks in `TimeSeriesMetrics`, pairwise-complete heatmaps, and tied-score ROC grouping. | Order-invariant ROC curves, aligned pairwise correlations, and strict NaN/Inf rejection (PR #80, #102). |
| **Wire-Protocol & SQLite Security (`SwiftDatabase`, `SwiftAgent`)** | `SSLMode.require` used plaintext; MySQL lacked `CLIENT_CONNECT_WITH_DB`; SQLite reused read-write handles. | Fail-closed `SSLMode.require`, dynamic `HandshakeResponse41` + `mysql_native_password` SHA-1, `SQLITE_OPEN_READONLY` (`readOnlyDbBox`), and SQL token guard. | Protocol-compliant MySQL authentication and C-API enforced read-only SQLite isolation (PR #102). |

### Methodology Caveats & Pre-`v3.13.2` Boundaries

- **Shared Binary Inputs**: Legacy `--research` fixtures used `BenchmarkLCG` for bit-identical IEEE 754 binary64 inputs; identical inputs do not guarantee bit-identical intermediate decompositions across different solvers.
- **Pre-`v3.13.2` Boundaries**: `3.12.0` predates the `3.13.1` CSV null-token round-trip/OOF `TargetEncoder`/`ShapiroWilk` fixes and the `3.13.2` G-033/G-037 ARIMA/SARIMA and G-035/G-036 TreeSHAP scope clarifications.
