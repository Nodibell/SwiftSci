# SwiftSci 3.13.0 Performance Overview

> [!NOTE]
> **Provenance Clarification (`v3.13.0`)**: There is **no independent `3.13.0` classical/standardized run directory** in `Benchmarks/Runs/`. Because `v3.13.0` modified only `SwiftLLM` and `SwiftNLP` (upstream `mlx-swift 0.33.0`, packed 4-bit/8-bit loading, binary parser bounds, and serialized embeddings) without changing `SwiftDataFrame`, `SwiftStats`, `SwiftPreprocessing`, `SwiftForecast`, or classical `SwiftML` hot paths, all classical and tabular figures below **carry forward the audited `v3.12.0` baseline unchanged**.

> [!WARNING]
> **v3.13.2 Audit Notice**: Legacy `--research` claims previously shown in `3.13.0` (`Holt-Winters >5000×`, `ARIMA(1,1,1) >9000×`, `SwiftLLM 0.121 ms vs 1.450 ms`) came from retired harnesses removed in `v3.13.2`. `ARIMA(1,1,1)` uses Hannan-Rissanen conditional OLS (not Statsmodels MLE), `ExponentialSmoothing` optimizes SSE via Nelder-Mead, and whole-process `Peak RSS` includes CPython/Pandas startup (~170–230 MiB).

Measured under **Methodology v2** (`Benchmarks/Runs/standard-3.12.0` and `migration-3.12.0`) on Apple M4 Pro (`arm64`, 24 GiB RAM, AC power, `macOS 27.2`), Swift `6.4` Release (`-O -whole-module-optimization`), against Python `3.14.6` (`Pandas 3.0.6`, `NumPy 2.5.3`, `SciPy 1.18.1`, `PyArrow 25.0.1`) and `Scikit-Learn 1.8.0` / `Statsmodels 0.14.6` / `SHAP` / `PyTorch 2.11.0` / `MLX 0.33.0`.

## Highlights & What Changed in 3.13.0

- **Upstream `mlx-swift 0.33.0` & Native Packed 4-Bit/8-Bit LLM Execution (`SwiftLLM`)**: Migrated from forked `mlx-swift` to upstream `ml-explore/mlx-swift 0.33.0`; added auto-detected packed 4-bit/8-bit loading (`loadQuantizedWeights`, `AffineQuantizationConfig`) keeping an 8B 4-bit model near **4.5–5.5 GB** instead of ~15 GB Float16, cross-shard split-tensor staging, and `ModelDownloader` + `TransformerDecoder.load(directory:maxSeqLen:)`.
- **Parser & Embedding Concurrency Hardening (`SwiftLLM`, `SwiftNLP`)**: Added unsigned/BOOL dtypes and overflow-checked shape + byte-count bounds in `SafeTensorsParser`, 1-byte boolean + bounds checks in `GGUFParser`, flattened `ByteLevel` post-processor support in `BPETokenizer`, and `NSLock`-serialized `AppleSentenceEmbeddingEngine` lookups eliminating batch > 16 `SIGSEGV` crashes.
- **Classical Baseline Parity vs `3.12.0`**: Zero edits to CPU, `SwiftDataFrame`, `SwiftPreprocessing`, `SwiftStats`, `SwiftForecast`, or classical `SwiftML` hot paths; `2,540/2,540` (`100.00%`) DocC API coverage.

- **Methodology v2**: Uses SHA-256 verified binary/CSV fixtures and separates shared apple-to-apple workloads, library-to-library comparisons, and hardware-specialized paths.
- **Reproduce Current Suites**: Legacy `--research` runners (`SwiftSciBenchmarks --research`, `Benchmarks/Python/benchmarks.py`, `Benchmarks/generate_fixtures.py`) were retired in `v3.13.2`.
