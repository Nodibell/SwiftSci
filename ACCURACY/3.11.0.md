# SwiftSci 3.11.0 Accuracy & Numerical Parity

> [!WARNING]
> **v3.13.2 Historical Audit Notice**: Combines audited `3.11.0` release checks with legacy `--research` benchmarks (`SwiftSciBenchmarks --research`, `Benchmarks/Python/accuracy_benchmarks.py`) retired in `v3.13.2`. `v3.13.2` also clarified that `ExponentialSmoothing` minimizes SSE (not Gaussian likelihood), `ARIMAModel` uses Hannan-Rissanen conditional OLS (with G-033/G-037 defects fixed in `v3.13.2`), and `TreeSHAP` covers DecisionTree/RandomForest regressors only (G-035/G-036).

Numerical, predictive, and statistical parity comparing **SwiftSci 3.11.0** (Swift 6, Accelerate BLAS/LAPACK & Metal) against **NumPy 2.3.5**, **Scikit-Learn 1.8.0**, **SciPy 1.17.1**, **Statsmodels 0.14.6**, **NLTK 3.10.3**, **SHAP 0.46.0**, and **PyTorch 2.11.0**.

## Correctness & Mathematical Enhancements in 3.11.0 (Audits 1–15)

| Subsystem | Prior Behavior (`3.10.3`) | `3.11.0` Enhancement | Mathematical Parity & Impact |
| :--- | :--- | :--- | :--- |
| **Explainability (`SwiftExplain`)** | Uncentered TreeSHAP leaf accumulation; unconstrained KernelSHAP drift; fixed LIME bandwidth collapsing for $D > 20$. | Centered TreeSHAP relative to $\mathbb{E}[f(X)]$; constrained WLS KernelSHAP (exact $M=1,2$); adaptive LIME $\sigma = 0.75\sqrt{D}$. | Exact Shapley efficiency $\sum \phi_i = f(x) - \mathbb{E}[f(X)]$ (DecisionTree/RandomForest regressors) & no LIME underflow (PR #76). |
| **Time-Series & State (`SwiftForecast`)** | Manual ETS smoothing; unbounded backtester/MASE division-by-zero; asymmetric Kalman covariance $P$. | Nelder-Mead SSE optimization in ETS; $h \ge 1$ / window $\ge 2$ bounds + MAE fallback; $P = \frac{1}{2}(P + P^T)$ with diagonal clip. | Reliable time-series CV and PSD covariance stability *(ETS optimizes SSE, not likelihood; PR #77)*. |
| **Trees, OLS & `TargetEncoder` (`SwiftML`, `SwiftPreprocessing`)** | Raw-count tree entropy; unpruned regression trees; Cholesky failure on singular OLS; singleton target leakage. | Normalized $p_i \log_2 p_i$ entropy; variance-reduction post-pruning; SVD pseudo-inverse OLS fallback; $m$-estimate smoothing ($m=10.0$). | Exact Scikit-Learn boundary parity, singular-matrix resilience, and leakage prevention (PR #74, #75). |
| **WordNet & VADER (`SwiftNLP`)** | Cycle-vulnerable undirected taxonomy distance; missing neutral token baseline and contrast rule in VADER. | 3-color DFS acyclicity check + $O(1)$ BFS LCA; `0.0` non-lexicon baseline, "but" contrast (`0.5×`/`1.5×`), caps/punctuation scaling. | 100% DAG acyclicity guarantee and strict NLTK VADER polarity alignment (PR #78). |

### Scope Boundaries & Methodology Caveats

- **Shared Binary Inputs & NaiveBayes**: `35.00%` NaiveBayes accuracy (Macro-$F_1$ `0.342`) validates implementation parity on a synthetic token fixture. `BenchmarkLCG` guarantees identical binary64 inputs, not bit-identical intermediate decompositions.
- **Pre-`v3.13.2` Boundaries**: `3.11.0` predates `3.13.2` G-033/G-037 ARIMA/SARIMA fixes and formal G-035/G-036 TreeSHAP scope boundaries.
