# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 3.0.x   | :white_check_mark: |
| 2.8.x   | :white_check_mark: |
| < 2.8   | :x:                |

## Reporting a Vulnerability

We take the security and integrity of **SwiftSci** seriously. If you believe you have discovered a security vulnerability in this project, please report it to us responsibly.

### How to Report

Please **do not** report security vulnerabilities through public GitHub issues.

Instead, report security vulnerabilities via:
1. **GitHub Private Vulnerability Reporting**: Go to the **Security** tab of this repository and click **Report a vulnerability**.
2. **Direct Contact**: Contact maintainers on GitHub ([@Nodibell](https://github.com/Nodibell)).

### What to Include in Your Report

- Detailed description of the vulnerability and its potential impact.
- Step-by-step instructions or sample code to reproduce the issue.
- Any suggested patches or mitigations.

### Response & Disclosure Timeline

- **Initial Acknowledgment**: Within 48 hours.
- **Triage & Status Update**: Within 5 business days.
- **Fix & Public Disclosure**: Coordinated release once a fix is verified and tagged.
