## Notable Domain Metrics & Known Scope Boundaries

### Semantic & Forecasting Root-Cause Findings

- **Intended `TypedColumn.unique` Contract (`248` vs Pandas `247`)**: On the `100k` nullable `[Double?]` fixture (`m = i % 250`), `CanonicalUniqueKey` intentionally separates SQL missing (`nil`, `m == 0`) from canonical IEEE `NaN` (`m == 1, 2`) and canonicalizes `±0.0` (`1 nil + 1 NaN + 1 ±0.0 + 245 values = 248`), whereas non-nullable `np.float64` merges `nil` and `NaN` (`247`).
- **CSV Null-Token Round-Trip Contract**: On `CSV_Write_100k_NullTokens` (`100k × 3`), SwiftSci writes `2,290,455` bytes vs Pandas `2,165,456` bytes (`+124,999` bytes from quoting literal `"NA"`/`"null"`/`"NaN"`/`"None"`/`""` values minus `1` trailing `\n`), preventing default `pd.read_csv` from collapsing `62,500` literal tokens with `12,500` `nil`s into `75,000` `NaN`s.
- **ARIMA `R² = -1.555` Root-Cause Investigation**: `git diff v3.12.0 -- Sources/SwiftForecast/Core/ARIMA.swift` confirmed estimator logic was byte-identical to `3.12.0` (only doc comments added). On the `period=12` sinusoidal series (`BenchmarkLCG(seed: 42)`, `N=500, h=24`), `Holt-Winters` achieves `R² = +0.997` and `Seasonal Naive` achieves `+0.463`, whereas non-seasonal `ARIMA(1,1,1)` yields `-1.555` (`RMSE=10.218`) vs Statsmodels `-11.014` (`RMSE=22.158`) because a non-seasonal model cannot represent deterministic seasonality.
- **Pre-`v3.13.2` Scope Boundaries**: `v3.13.1` predates the **G-033** ARIMA/SARIMA polynomial validation fix, **G-037** differenced `fittedValues` fix, and formal **G-035/G-036** TreeSHAP scope boundaries introduced in `v3.13.2`.

For timing measurements and OS-variance diagnostics, see the [Companion Performance Report](../PERFORMANCE/3.13.1.md) and [`accuracy.deep.md`](../Benchmarks/Reports/v3.13.1/accuracy.deep.md).
