## Correctness & Mathematical Enhancements in 3.14.0

| Subsystem | Prior Defect / Gap | `3.14.0` Resolution | Verification Scope |
| :--- | :--- | :--- | :--- |
| **G-035: `TreeSHAP` for `GradientBoostedTreesRegressor` & Cover Metadata** | `TreeSHAP` lacked `GradientBoostedTreesRegressor` support, and `FlatTreeNode` did not record empirical node sample cover (`cover`). | Added `explain`, `explainDetailed`, and `explainBatch` for `GradientBoostedTreesRegressor`, introduced `TreeNodeWeighting` (`.uniformLeaf` and `.empiricalCover`), and populated `FlatTreeNode.cover` across decision trees, random forests, GBDTs, and `GradientBoostedTreesModelState` persistence. | Verified local accuracy, batch parity, `2^K` coalition enumeration across `.squaredError`, `.absoluteError`, and `.huber`, plus Python `shap.TreeExplainer` (`maxShapDiff = 1.332e-15`, `maxBaseDiff = 5.551e-17`, `maxPredDiff = 8.882e-16`, `maxEffDiff = 8.882e-16`). |
| **G-036: Per-Class Probability `TreeSHAP` & `ForestProbabilityMode`** | Classifier `TreeSHAP` explained encoded class-label output rather than per-class probabilities, and `RandomForestClassifier` lacked explicit `.softLeafDistribution` vs `.hardVote` probability selection. | Added `explainClassDetailed`, `explainAllClassesDetailed`, and `explainBatchClass` for `DecisionTreeClassifier` and `RandomForestClassifier`, populated `FlatTreeNode.classDistribution`, and added `RandomForestClassifier.predictProbability(features:mode:)` (`ForestProbabilityMode`). | Verified local accuracy, class-sum balance, and `2^K` coalition parity across `C = 2, 3, 5`, plus Python `shap.TreeExplainer` parity on `DecisionTreeClassifier` (`maxShapDiff = 1.665e-16`) and `RandomForestClassifier` (`maxShapDiff = 1.110e-16`). |
| **G-038: `ReActAgent` Chat Templates, Stop Sequences & `GenerationConfiguration`** | `ReActAgent` lacked chat-template formatting in `stream`/`run`, `ChatTemplate` lacked canonical turn-end `defaultStopSequences`, and `TransformerDecoder` did not expose structured `GenerationConfiguration` sampling/stop controls. | Added `ReActAgent.stream(query:chatTemplate:...)`, `ChatTemplate.defaultStopSequences` across all 6 families, `LLMOptions.stopSequences` / `stopTokenIDs`, `GenerationConfiguration` (`generation_config.json` parsing + `makeLLMOptions`), and `TransformerDecoder` chat-templated generation with stop-sequence/token halting. | Verified across `ReActAgent3140Tests`, `ChatTemplate3140Tests`, and `GenerationConfigStopSeq3140Tests`. |
| **G-039: `SwiftVision` Dataset Metadata, Cropping & Split `ImageFolder` Loaders** | Vision training workflows lacked built-in YOLO `data.yaml` metadata parsing, detection/background crop extraction, and split folder dataset loaders. | Added `YOLODatasetMetadata` YAML parsing, `ImageDataset.crop` / `cropAll` / `sampleBackgroundCrop`, and `ImageDataset.loadFolder` / `loadSplitFolder` (`ImageFolderDataset`, `SplitImageDataset`). | Verified across `VisionDatasets3140Tests` (dict/list YAML formats, comments, quotes, crops, and train/val/test split loading). |
| **G-040: `TrainedVisionClassifier`, `OneVsRestClassifier` & Core ML Vision Pipeline** | End-to-end Vision scene classification and Core ML `VisionFeaturePrint.Scene` composite pipeline export (`PipelineClassifier`) lacked a unified actor and `OneVsRestClassifier` `ClassifierEstimator` export conformance. | Made `OneVsRestClassifier` conform to `ClassifierEstimator` (`getBias`, `getWeights`, `getWeightsAndBias`, `decisionFunction`, `predictProbability`), added `CoreMLExporter.exportBinaryMLPClassifier`, `exportBinaryVisionFeaturePrint`, and `exportVisionClassifierPipeline` (`VisionScenePrintRevision`), and introduced `TrainedVisionClassifier` (`.oneVsRest`, `.mlp`, `.randomForest`). | Verified via `OneVsRestCoreML3140Tests` and `TrainedVisionClassifier3140Tests` with compiled Core ML `MLModel` + `VisionFeaturePrint.Scene` numerical parity across `OneVsRest`, `MLP`, and `RandomForest`. |
