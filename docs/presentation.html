01 / SwiftDataFrame

Arrow Zero-Copy DataFrames

Memory-mapped CSV/JSON parsing with SIMD bitmask filtering and direct HTTP URL ingestion.

⚡ 15.09 ms for 100k rows (1.36× vs Pandas)
DataFrameUsage.swift
import SwiftDataFrame let df = try DataFrame(columns: [ TypedColumn<Int64>(name: "id", values: [1, 2, 3]), TypedColumn<Double>(name: "score", values: [88.5, 92.0, 74.5]) ]) // SIMD Bitmask Row Filter let filtered = try df.filter { r in (r.double("score") ?? 0) >= 85.0 }
✓ Filtered 2 rows in 0.002 ms
02 / SwiftStats

Accelerate vDSP Statistics

Hardware-accelerated SIMD reductions, Student-t / Chi-Square distributions, ANOVA, and Pearson correlation.

StatsUsage.swift
