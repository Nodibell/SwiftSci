# SwiftSci 3.11.0 Performance Overview

> [!WARNING]
> **v3.13.2 Historical Audit Notice**: `3.11.0` combines standardized `standard-3.11.0` (`macOS 27.0.1`, Swift `6.4`, Python `3.14.6`) with legacy `--research` tables (`3` rounds × `7` iterations, `2` warmups, `seed=42`, Python `3.11.9`, NumPy `2.3.5`, Pandas `3.0.2`, Scikit-Learn `1.4.2`, Statsmodels `0.14.2`, SHAP `0.44.1`, PyTorch `2.11.0`). Legacy `--research` harnesses were retired in `v3.13.2`: `Holt-Winters >5000×` (SSE vs likelihood), `ARIMA(1,1,1) >9000×` (Hannan-Rissanen OLS vs Statsmodels MLE), and `SwiftLLM 0.121 ms vs 1.450 ms` are non-comparable, and whole-process `Peak RSS` (`ru_maxrss`) includes Python interpreter/library overhead (~148–691 MiB).

---

## Highlights & What Changed in 3.11.0

- **SIMD-Accelerated Hash Join (`4.15×` Speedup vs `3.10.3`)**: Vectorized hash probe and contiguous column equality dispatch over primitive buffers (`Int64`, `Int32`, `Double`, `Float`, `String`, `Bool`) eliminated `any Any` boxing, cutting `100k` inner join latency from `11.20 ms` (`3.10.3`) to **`2.70 ms`** (**SwiftSci 3.63×** vs Pandas `9.80 ms`) (PR #73).
- **Direct Prepared Matrix Preprocessing (`42 → 16 MiB` Intermediate Heap)**: Added zero-copy `prepareNumericMatrix` and `transform(consuming:)` (`Imputer`, `StandardScaler`), improving `StandardScaler` from `2.79 ms` to **`1.97 ms`** (**1.42×** vs `3.10.3`) and boosting end-to-end inference speed by **1.16–1.32×** (PR #71, #72).
- **Faster CSV Ingestion (`1.81×` vs `3.10.3`) & 1M-Row Scaling**: Streamlined buffer ingestion and zero-copy Arrow imports reduced `100k` CSV read from `6.80 ms` to **`3.76 ms`** (**SwiftSci 2.76×** vs Pandas `10.38 ms`) and `1M`-row CSV read from `8.92 ms` to **`6.95 ms`** (**SwiftSci 9.65×** vs Pandas `67.06 ms`, `49.8 MiB` vs `412.0 MiB` process RSS) (PR #61).
- **Bounded Inference, Core ML Session Retention & MLX `0.32.3` SIMD**: Added hardware-aware memory admission, retained Core ML execution sessions, batched MLP scratch prediction, and Float16 SIMD backports for Llama 3.2 (PR #49, #50, #52, #60, #62–#70).
