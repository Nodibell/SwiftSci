## 1. Mandatory Release Gate G-037 — **FIXED AND VERIFIED**

### Root Cause in `v3.13.1`

In `v3.13.1`, both `ARIMAModel.integrate(fittedDiff:original:d:isForecast:)` (`Sources/SwiftForecast/Core/ARIMA.swift`) and `SARIMAModel.integrate(fittedDiff:original:d:D:s:isForecast:)` (`Sources/SwiftForecast/Core/SARIMAModel.swift`) reconstructed in-sample `fittedValues` (`isForecast == false`) via **open-loop cumulative integration** starting from the earliest boundary values:
- `var lastVal = levelSeries[0]; ... val = lastVal + diffVal; lastVal = val` (non-seasonal `d`), and
- `val = reconstructed[i] + current[i]` (seasonal `D`, chaining previous **predicted** values instead of observed values `subLevelSeries[i]`).

Even though one-step differenced innovations were computed closed-loop (`diffResiduals[t] = diffSeries[t] - diffFitted[t]`), accumulating `diffFitted` open-loop accumulated error as a random walk across `n` steps and destroyed alignment on the original scale. In addition, when `ARIMAModel` had exogenous regressors (`ARIMAX`), `fittedValues` omitted `withExogenousComponent(...)`. That mismatch forced Saura to apply a temporary display-side reconstruction (`fitted[t] = actual[t] - residual[t - warmUp]`).

### Fix & Mathematical Contract (`v3.13.2-candidate`)

1. **Closed-loop one-step-ahead integration (`ARIMA.swift`, `SARIMAModel.swift`):**
   When `isForecast == false`, integration anchors every step `t >= warmUp` (`warmUp = d` for `ARIMAModel`, `warmUp = d + D * s` for `SARIMAModel`) to the **observed** sub-level series (`levelSeries[i] + diffVal`, and `subLevelSeries[i] + diffVal`), with `withExogenousComponent(...)` restored for `ARIMAX`.
2. **Exact scale and alignment contracts:**
   - `fittedValues.count == series.count`
   - `residuals.count == series.count - warmUp`
   - Boundary indices `t in 0..<warmUp`: `fittedValues[t] == series[t]` (seed observations, `0.0` diff residual).
   - Post-warmup indices `t in warmUp..<series.count`: strict closed-loop one-step-ahead prediction on the original data scale, satisfying:
     `residuals[t - warmUp] == series[t] - fittedValues[t]`.
3. **Verification Results:**
   - Dedicated unit/regression suite [`Tests/SwiftForecastTests/ARIMASARIMAFittedValuesTests.swift`](../Tests/SwiftForecastTests/ARIMASARIMAFittedValuesTests.swift): verifies `ARIMAModel` (`d = 0, 1, 2`), trivial `ARIMA(0, 1, 0)`, `ARIMAX`, `SARIMAModel` (`D = 1, 2`), `AutoARIMA`, AirPassengers (`n = 144`), exact causal non-leakage under future `+5000` perturbation at `t = 143`, and `residual[t - warmUp] == actual[t] - fitted[t]` within `1e-9` / `1e-10`.
   - `scientific_validation.json` Stage A gate checks:
     - `ts_sarima_airpassengers_144_g037`: `warm_up=13`, `fitted_count=144`, `residuals_count=131`, `max_warmup_diff=0.0`, `max_identity_diff=5.68e-14`, `saura_formula_exact_match=true`, in-sample `RMSE=28.3051`, `R²=0.8554`, `late_1960_max_err=23.7976`.
     - `sarima_ap_ro` (origins `108/120/132`): all origins `max_warmup_diff=0.0`, `max_identity_diff=5.68e-14`, `saura_formula_exact_match=true`.
     - `ts_arima_syn500_matched_hr`, `ts_arima_dgp_syn500_matched_hr`, `arima_dgp_ro`: `warm_up=1`, `max_warmup_diff=0.0`, `max_identity_diff=1.42e-14`, `saura_formula_exact_match=true`.

## 4. Known Deferred Limitations

1. **G-035 (GBDT regressor TreeSHAP):** Currently `TreeSHAP` explains single `FlatTreeNode` structures (`DecisionTreeRegressor`, `DecisionTreeClassifier` single tree, or averaged `RandomForest*` ensembles using uniform `1.0` leaf weights). The adapter for `GradientBoostedTreesRegressor` is deferred.
2. **G-036 (class-probability TreeSHAP):** Class-targeted attribution for classifier ensembles is deferred. **Large-feature approximation.** `K > 12` distinct split features uses deterministic `2048`-permutation Monte Carlo approximation (`O(T · M · K · depth)`); Lundberg et al.'s `O(T · L · D^2)` dynamic-programming polynomial algorithm is deferred.
3. **`Stats.skewness` / `Stats.kurtosis` `ddof = 1` Formula:** Preserved for v3.13.x API compatibility; differs from Fisher's `g1`/`g2` (`SciPy bias=True`) and `G1`/`G2` (`SciPy bias=False`), especially at small `N`.
4. **`TimeSeriesAnomalyDetector` Trended Edge Effect:** Boundary indices `[0..<p/2]` and `[(n-p/2)..<n]` fall back to `medTrend`, which can trigger false positives on strongly trended series with low `threshold` (e.g., `threshold = 3`).
5. **macOS Apple Silicon Scope Only:** All validation executed on `Apple M4 Pro (arm64)` (`macOS 27.2.1`); `x86_64` and clean Stage B release artifacts remain outside this candidate report until final commit/tag.
